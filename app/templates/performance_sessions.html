“Limited by” comes from the misses of the classes below target. The constraint is diagnosed from those misses and, with B300 telemetry, from vLLM and GPU signals over each level's measured window: KV cache occupancy and preemptions, prefix-cache hits against the reuse the session histories allow, waiting and running requests, prompt against generated tokens, and GPU activity. Telemetry covers all traffic of the deployment, not only this benchmark. The user model is an estimate until it is fitted to session traces; the result applies to this model, these SLOs and this deployment state.
